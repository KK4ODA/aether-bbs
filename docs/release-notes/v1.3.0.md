**Aether BBS now tells you when there's a new version, and installs it for you.**

## Updates at startup

- When Aether BBS starts, it checks GitHub for a newer release. If there is one, it shows
  what's new with **Update now**, **Remind me later** and **Skip this version**. It also warns
  you if stations are connected, because updating restarts the BBS.
- **Update now** works for a downloaded ZIP as well as a git clone:
  - **ZIP:** the new release is downloaded and copied over your BBS folder. Every file it
    replaces is saved first under `backups/update-v<old>-<date>/`. If the copy fails part-way,
    the old files are put back. Your `messages/`, `files/`, `logs/` and settings are never
    touched.
  - **git clone:** moved to the release tag. If you've edited tracked files, it asks you to
    commit or stash them first.
- If the new version needs new Python packages, they are installed with pip, then the BBS
  restarts.
- In **Settings → About & Updates**, **Check for Updates** opens the same window. A git clone
  can follow every change on `master` instead of releases only, and you can un-skip a
  version you skipped.

## Upgrading from 1.2.0

1.2.0 can only update a git clone. If you installed from a ZIP, download this release by hand
once and unpack it over your BBS folder. From then on, Aether BBS updates itself.
