**Windows: the updater installs the update after the BBS quits.**

After **Update** the BBS closes and a small script is supposed to run the new installer, then start
Aether BBS again. On some computers the installer never ran. The script now:

- runs in a hidden console (it used to have none, so each step it ran opened a window of its own
  or failed);
- uses Windows' own `find` even when Git or Cygwin puts another one first on the PATH;
- works when the Windows user name or Temp folder has non-English letters;
- stops a BBS that has not finished quitting after about two minutes, so the update does not wait
  forever;
- notes each step in `%TEMP%\aether-bbs-update\update.log`, and the installer writes its own
  `setup.log` beside it.

**Note:** the copy you have now still updates with the old script.  If **Update** does not finish
on your computer, install this release once by hand with `AetherBBS-1.3.7-windows-setup.exe`;
later updates use the new script.
