**Windows: Update installs the new version again.**

After **Update** the BBS closes and a small script is meant to run the new installer, then start
Aether BBS again. In 1.3.2 to 1.3.6 that script never got as far as the installer, so the BBS
closed and nothing happened. And when Aether BBS is installed for all users (in Program Files)
the installer also needs an administrator's approval, which Windows asked for only after the BBS
had closed, from the background, where its prompt went unseen.

Now:

- Windows asks for approval **while the BBS is still open**, when you click **Update**. Say No and
  the update is called off; the BBS keeps running.
- The installer keeps the install where it is (all users or just you), and the new version starts
  with your own rights, not as administrator.
- The script runs in a hidden console, copes with non-English letters in the user name or Temp
  folder, and uses Windows' own `find` even when Git or Cygwin puts another first on the PATH.
- If the BBS has not finished quitting after about two minutes, the script stops it rather than
  wait forever.
- Each step is noted in `%TEMP%\aether-bbs-update\update.log`; the installer writes its own
  `setup.log` beside it.

**Note:** the copy you have now still updates the old way. For an all-users install, download
`AetherBBS-1.3.7-windows-setup.exe` from this release and run it once by hand; later updates work
from the **Update** button.
