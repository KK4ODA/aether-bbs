**Settings → Winlink Fwd Mgr is removed.**

Its settings (list mode and the number of callsigns) never had any effect: the BBS never built
that list. Winlink mail works as before:

- the sysop's **Poll Now** fetches mail for the gateway callsign and the **Forward For**
  callsigns on the Winlink page;
- an RF user registered with **WLREG** fetches their own mail with **WL**.

An old settings file that still has the section loads as before; the section is ignored.
