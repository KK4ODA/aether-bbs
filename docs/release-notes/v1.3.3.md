## Security fixes

- A B2F client could collect another station's private mail by typing that station's callsign
  in its banner. Mail now goes only to the station on the RF link. Real Winlink clients
  (whose banners name the program, not the callsign) now get their mail.
- An RF user could read or delete other users' private messages by number with `R` and `K`.
  `R`, `K`, `RB` and `KB` now use the numbers from your last listing.
- A file upload could name a file area that doesn't exist, or send more data than it declared.
- A forwarding partner could fetch private messages with `FWD GET`. Only bulletins are served.

## Reliability fixes

- The modem link no longer drops after a quiet spell, and reconnects keep trying (5 s up to
  once a minute) instead of giving up. PTT is released when the modem link is lost.
- When the RF link drops mid-session, the BBS ends the session at once instead of holding its
  only session slot for 10 minutes. Half-typed messages are not saved.
- Bulletins are marked forwarded only after the partner has them, and a bulletin cut off
  mid-transfer is dropped instead of saved short.
- Winlink: a message is marked seen only once it is stored; mail stuck "sending" after a crash
  is retried.
- Inbound email: messages are marked read on the server only once delivered, and the same email
  is never delivered twice.
- APRS-IS: a silent connection is detected and reconnected.
- **Check for Updates** in Settings no longer hangs.
- Saving Settings no longer resets settings the dialog does not show. A settings file with one
  bad section keeps the rest instead of resetting everything.
- Closing from the system (logout, `kill`) shuts down cleanly.
- Changing a password for an existing user works.
