**A session that times out now hangs up the link.**

When a station sat idle past the session timeout, the BBS sent `Session timeout. 73 de BBS.` and
ended the session, but never told the modem to disconnect. The RF link stayed up, and the caller's
terminal still showed the session as connected. The two-minute waits for unknown and pending
stations did the same.

Now the BBS sends DISCONNECT after the timeout message, so the link drops and the caller's
terminal returns to Connect. A link that drops by itself is still not answered with a timeout
message.
