**Seven changes from the code audit, decided by the sysop.**

## Changes you will notice

- **Winlink sends only what you send to Winlink.** Every Winlink poll used to send any waiting
  message for another callsign to Winlink, including mail for your own RF users, received
  bulletins and inbound email, which then disappeared from RF pickup. Now a message goes to
  Winlink only when it was sent there: the RF `SW` command, an internet (@) address, or the new
  **Send via Winlink** box when you write or reply in the BBS window (ticked by default when
  you reply to Winlink mail). Everything else waits for RF pickup.
- **Winlink messages from the queue go out again.** Queued messages failed every time they were
  handed to Pat.
- **The SMTP fallback is gone.** It never sent anything: nothing ever put a message in its queue.
  Its settings pages are removed, and its saved SMTP passwords (kept in plain text) are deleted
  from the settings file the first time this version starts. Inbound email and the Winlink
  forward list stay, under **Settings → Internet Email**.
- **The operational mode is enforced.**
  - Posting bulletins and uploading files need SYSOP in EMCOMM, TRUSTED in restricted and
    APPROVED in open. In EMCOMM, TRUSTED users can no longer post or upload.
  - Sending messages, posting bulletins, uploading files, registering and failed logins are
    rate-limited (a quarter of the normal limits in EMCOMM, double in open).
  - EMCOMM blocks a callsign after 5 failed logins.
- **The forwarding server only talks to your neighbours.** A bulletin forwarding connection from
  a callsign that is not an enabled neighbour in **Settings → Forwarding** is refused. Make sure
  every BBS that forwards to you is in that list.
- **Settings → Save says when a restart is needed.** Inbound email, the Winlink forward list,
  forwarding neighbours and server, turning APRS on, adding or enabling a modem instance, an
  instance's PTT or bandwidth, and the update check interval take effect after a restart; Save
  now lists the ones you changed.
- **Settings → Revert works.** It puts the saved values back in the form.

## Security

The inbound email (IMAP/POP3) password is now encrypted in the settings file, like the Winlink
password. This is one-way: if you go back to an older version, enter that password again.
