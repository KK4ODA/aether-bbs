**Winlink mail for every SSID, honest Winlink senders, and settings that apply on Save.**

## Winlink

- **A station sees its Winlink mail whatever SSID it connects with.** Winlink mail is filed
  under the base callsign (KK4ODA), but `L`, `U`, `N` and the new-mail notice only looked at
  the callsign exactly as connected, so KK4ODA-7 never saw it. A mailbox now holds mail to the
  callsign as connected and to its base callsign (KK4ODA-7 sees KK4ODA-7 and KK4ODA, not
  KK4ODA-5). Nothing is listed twice.
- **`WLREG` is kept for the base callsign**, like the BBS password, so every SSID shares it,
  and `WL` checks the base callsign's Winlink mail. Registrations made with an SSID before
  this version still work.
- **Messages sent through Winlink say who wrote them.** The Winlink system accepts a message
  only from an address the account that logged in owns. **Poll Now** logs in as your gateway
  callsign, so it sends every queued message from the gateway; one written by someone else
  now starts with a line such as `From KK4ODA-7 via W1AW-10 BBS` (or
  `From EOC (KK4ODA-7) via W1AW-10 BBS` under a tactical address). Before, nothing showed who
  wrote it, and `TACTICAL` wrongly said messages would be sent from the tactical address.
  When a user registered with `WLREG` types `WL`, the BBS logs in to their own account, and
  their own queued messages now go out from their own callsign.
- **Turning Winlink on or off, or changing its settings, works on Save.** Before, Pat and the
  inbox check started only if Winlink was on when the BBS started. Now Save starts Pat (with
  *Auto-launch Pat* on) and the inbox check, stops Pat when Winlink is turned off, and
  restarts Pat when its settings change. The Winlink panel's **Poll Now** follows too.
- **An empty Pat Executable uses the Pat found** on the PATH or in the usual install folders,
  as the tooltip always said. Before, it was only shown on the settings page.

## Messages and email

- **Old messages are removed on their own**, at start-up and every 6 hours, the same as
  **🗑 Expire Old**. Before, nothing expired until you pressed the button. A change to
  *Message Max Age* applies to messages that arrive after it.
- **Gmail plus-addressing works for inbound email.** With BBS Domain `gmail.com`, an email to
  `youraccount+kk4oda@gmail.com` is stored for KK4ODA (case does not matter). Before, the part
  after `+` was ignored and the email was skipped. An email to one of your tactical addresses
  (`youraccount+eoc@gmail.com`) is stored for it too and raises its priority alert.

## Users

- **The sysop callsign is always in User Management.** Its row was made only on the very first
  start, so after you changed the Sysop Callsign there was no way to give the new one a
  password: Add User refused it and **🔑 Password** needs a row. The row is now added at
  start-up and when you save Settings.
- **"Require password" tells the user what to do.** A user without a password was told it would
  be sent by Winlink once approved, which the BBS never does by itself. Now they are told to ask
  the sysop for one (by Winlink, email, phone or in person) before they are disconnected. Set
  it with **🔑 Password** and send it. There is still no way to set a first password over the
  air, on purpose.

## Settings

- **The README's example instances load.** Its Soundmodem instance was refused ("Port 8300 is
  used by more than one enabled instance") because the port check counted the CMD/Data ports a
  Soundmodem instance does not use (and the form hides). A Soundmodem instance now counts only
  its AGWPE port, in the settings file, the Instances page and at start-up.
- **New settings files have no sample tactical address.** `BRECKEN` is no longer added; one
  already in your settings stays.
- **Save says Max Sessions needs a restart.**

## Smaller fixes

- `FG` waits 10 s for `CANCEL`, as it says, then sends the file. Before, it waited for you to
  type a line, up to the session timeout.
- The unknown-station *Access Restricted* box lines up.
- Tooltips: the packet log file is `packet_frames.log`; *Advertise* lists a tactical address to
  RF users when they connect and in `I` (not the APRS beacon); the dashboard's upload notice
  gives each mode's real upload rule; *Require password*, *Message Max Age*, *Pat Executable*
  and the Winlink page note say what really happens.
- The `WLREG` prompt names Aether Term. The README no longer claims the sysop can join chat
  rooms from the BBS window.
