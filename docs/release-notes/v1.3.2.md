**Installers for Windows, Mac and Linux. No Python needed.**

## Installers

| Computer | Download |
|---|---|
| Windows 10/11 (64-bit) | `AetherBBS-1.3.2-windows-setup.exe` |
| Mac (Apple silicon) | `AetherBBS-1.3.2-macos.dmg` |
| Linux (x86-64) | `AetherBBS-1.3.2-linux-x86_64.tar.gz` |

- **Windows:** run the setup. It installs for you alone, with no administrator prompt, unless
  you choose all users, and adds Aether BBS to the Start menu.
- **Mac:** open the disk image and drag **Aether BBS** into Applications.
- **Linux:** unpack the archive in a folder you own and run `AetherBBS/AetherBBS`.
  `install-desktop-entry.sh` in that folder adds it to your application menu. You need
  `libxcb-cursor0` (Debian/Ubuntu) or `xcb-util-cursor` (Fedora/Arch).

The installers are not code-signed yet, so the first start shows a warning. On Windows click
**More info → Run anyway**. On a Mac open **System Settings → Privacy & Security** and click
**Open Anyway**.

An installed Aether BBS keeps its settings, messages, files and logs in your profile folder
(`%APPDATA%\aether-bbs` on Windows, `~/Library/Application Support/aether-bbs` on a Mac,
`~/.config/aether-bbs` on Linux). Uninstalling leaves them there.

## Updates for installed copies

When a new release is out, **Update now** downloads its installer. On Windows the installer runs
by itself once the BBS has closed, then starts the new version. On Linux the new version
replaces the old one and the BBS restarts. On a Mac the disk image opens for you to drag the
new app into Applications.

## Running from source

Nothing changes: `python main.py` works as before, and source and git copies keep updating
themselves the same way.

If you switch from a source copy to an installer, your settings carry over. To keep your
messages and files, copy `messages/` and `files/` from the source folder into the profile
folder above.
